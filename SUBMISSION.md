## How we used Switch

Switch puts the owner, triager, and fixer in one Mattermost room, where the report, Supabase log evidence, handoff, proposed SQL, explicit human approval, and verification share the same context. The triager and fixer are Claude Code agents addressed by role; the fixer is owner-addressable only and must wait for the owner to approve the exact database write before running it.
